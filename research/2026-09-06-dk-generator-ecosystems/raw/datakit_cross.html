CrossManager

With CrossManager, converting the CAD files of your choice is easy.
  • 01 - You select one or more files.
  • 02 - You convert them into the chosen format.
  • Available with GUI (Graphical User Interface) and/or CLI (Command Line Interface).
  • Does not require an external licence.
  • Easy to use.
  • Reliable conversion of 2D and 3D data.
  • Regular updates

    directly on the Datakit website for users with an up-to-date maintenance contract.

A CrossManager licence  includes:
  • the conversion engine,
  • a reading module for each file format to be read,
  • a write module for each format to be written.
Our solution also includes  maintenance:
  • quarterly updates (to be able to read and write the latest versions of native files),
  • technical support.
CrossManager Product Range
  • CrossManager
  • Convert 2D and 3D CAD files from a simple GUI program, on premise, without the need of external third-party CAD licenses. Easy to use, updated quarterly depending on your maintenance contract. Available on PC, Windows 64 bits versions.
  • CrossManager Advanced
  • CrossManager Advanced extends Cross-Manager to support unlimited file conversions within the GUI. Includes processing of entire folders recursively.
  • CrossManager CLI Command Line Interface
  • CrossManager CLI (Command Line Interface) will allow tight integration into your workflow (PLM, background services, scripts). It comes as a lightweight no-GUI executable that can run on various platforms, including Windows, Linux and macOS. Licensing can be adapted to your organization size and software/hardware environment.

  • How licences work

    You must have a licence to use CrossManager.
    You can buy one by contacting us, or apply for a trial license to test the quality of the software.
    Each input or output format requires its own licence to work.
    That way, you can order your "à la carte" configuration according to your needs, and only buy the formats you need.
    We provide three types of licenses :
    - single licences, that operate on a single workstation.
    - floating licences, installed on a licence server so that CrossManager can be used on different workstations. You can choose the number of “tokens”, which defines the number of users who can use the software simultaneously.
    - remote licenses, installed on a single workstation, but which can be used remotely from another workstation.

CrossCad/Plug-in

Integrated converters
for SolidWorks or Rhino.
These SolidWorks and Rhino plug-ins let you read formats that these softwares do not natively support or and save files in different formats than those of SolidWorks or Rhino.
  • 01 - You install the plug-in.
  • 02 - The Datakit menu is created in the SolidWorks or Rhino software.
  • 03 - You then have direct access to the Datakit menu for all of your model import or export operations.
  • Easy to install.
  • Easy to use.
  • Reliable conversion from many formats.
  • Regular updates directly on the Datakit website for users with an up-to-date maintenance contract.
