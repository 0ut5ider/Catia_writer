Description

The Part Import tool opens a dialog that allows you to import the following CAD file formats: IGES, STEP and BREP into the current document.

Usage

  1. Set up the Import Export Preferences in the Preferences Editor.
  2. Go to the menu Part → Import CAD.
  3. Select the file to be imported.
