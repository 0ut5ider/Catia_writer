Glossary

  • Assemblies : Assembly components, instances, placements, configurations and catalog entries.
  • BREP : Geometrical and Topological entities (solids, shells, faces, surfaces). Can be converted to meshes using the tesselation module.
  • Wireframe : Sets of 3D free curves, sketches.
  • Meshes : Meshes included in the CAD file as display information or for design purpose.
  • Notes/PMI/FDT : Free notes, Product Manufacturing Information, set of Annotations/Dimensions/Tolerancing/Datums entities, incl. links to geometries/components.
  • Model Display : Model views including filtering, sections and cameras.
  • Metadata : PDM file properties, generic custom properties (named values)
  • Rendering : Surface lighting and texturing information.
  • Material : Definition of physical properties of used material (name, density, conductivity, strengthâ¦)
  • Features : Parameters to be used in downstream applications (holes, patterns, threads, pockets and others depending on the CAD format)
  • Constraints : Assembly constraints between components (e.g. fixed, parallel, joint, contact etcâ¦)
  • UUID/ Persistent name : Unique identifiers for CAD entities (possibly persistent depending on the CAD format)
  • Drawings : 2D Sheet data including geometries and PMI entities.
  • Part Tree : Part construction tree, feature history and parameters.
